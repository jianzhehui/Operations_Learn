# Linux 基础运维速查

## 系统初始化顺序

1. 设置并验证主机名：`hostnamectl set-hostname`、`hostnamectl status`。
2. 确认地址、路由和 DNS：`ip address`、`ip route`、`resolvectl status` 或发行版对应工具。
3. 备份软件源配置，再更新仓库缓存并检查可用仓库。
4. 检查 SELinux 和防火墙状态，不应把关闭安全机制当成默认处理方式。
5. 配置时间同步，并通过 `chronyc sources -v`、`chronyc tracking` 验证。

## Shell 与权限

| 需求 | 常用工具 | 验证重点 |
| --- | --- | --- |
| 采集 CPU/内存/磁盘 | `lscpu`、`free`、`lsblk`、`df`、`du` | 明确单位、设备与挂载点 |
| 处理结构化文本 | `grep`、`awk`、`sed`、`sort`、`uniq` | 先用小样本验证字段位置 |
| 丢弃输出 | `/dev/null`、`>/dev/null`、`2>/dev/null` | 不要隐藏排障所需的错误 |
| 修改权限 | `chmod`、`chown` | 区分文件与目录的 `rwx` 含义 |

## 日志排查顺序

1. 明确时间范围和日志来源。
2. 先保留原始日志，再过滤成功与失败事件。
3. 用 `awk` 提取字段前，抽查多种日志格式；不能假设所有行的列号一致。
4. 聚合后回查原始行，避免把解析错误当成结论。

## 风险与回滚

- 修改软件源、网络和服务配置前先创建带时间标记的备份。
- `sed -i` 可能以新文件替换软链接；需要修改链接目标时使用真实路径或 `--follow-symlinks`。
