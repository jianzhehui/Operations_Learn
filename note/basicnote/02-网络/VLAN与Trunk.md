# VLAN 与 Trunk

## 快速结论

- VLAN 在同一套二层网络设备上划分广播域，实现逻辑隔离。
- Access 端口通常只承载一个 VLAN，面向终端设备。
- Trunk 链路可使用 802.1Q 标签承载多个 VLAN，常用于交换机之间或交换机与虚拟化宿主机之间。
- VLAN 之间默认不能直接通信，需要三层交换或路由设备提供跨 VLAN 路由，并配合访问控制策略。

## 规划清单

1. 记录 VLAN ID、用途、网段、网关和允许访问的目标。
2. 标明每个物理/虚拟端口的 Access 或 Trunk 模式。
3. 明确 Trunk 允许通过的 VLAN 列表与 native VLAN 策略。
4. 先画拓扑，再配置并逐段验证同 VLAN 与跨 VLAN 通信。
