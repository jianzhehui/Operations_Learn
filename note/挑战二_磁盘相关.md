## 9、`su -`与`sudo -i`

`su -` 表示切换到 root 用户并加载 root 的完整登录环境

`sudo -i` 表示以 root 身份登录,同样会获得 root 的登录shell和环境。

`su -`需要root密码，Ubuntu默认root没有密码

`sudo -i`需要当前用户密码
