#### 1.4 使用smb、nfs、ftp、http将专用目录发布出来(匿名只读)

###### 1.4.1 smb方法

停止防火墙和selinux

```shell
systemctl stop firewalld
systemctl disable firewalld

vim /etc/sysconfig/selinux
SELINUX=disabled
```

安装samba服务

```shell
yum install -y samba samba-client samba-common
```

更改目录的所有者为 nobody

```shell
chown -R nobody:nobody /data/fileserver
```

设置目录权限

```shell
chmod -R 755 /data/fileserver
```

配置 Samba

```shell
cp /etc/samba/smb.conf /etc/samba/smb.conf.bak
#备份原有的配置文件

vim /etc/samba/smb.conf
```

```shell
[global]
		workgroup = WORKGROUP
		map to guest = bad user
		guest accout = nobody
		#允许匿名用户作为访客登录
		
[fileserver]
#在文件的最末尾，添加共享目录配置：
    comment = Anon Read Only Share
    文件夹描述
    path = /data/fileserver
    #实际路径
    public = yes
    #允许访问
    browseable = yes
    #文件夹可见
    writable = no
    #只读权限设置
```

启动并设置开机自启

```shell
systemctl start smb nmb
systemctl enable smb nmb
```

验证

```shell
smbclient -L //ip -N
#列出共享

smbclient -L //ip/data/fileserver -N
#进入共享

systemctl status smb nmb
#查看服务状态
```

找出 CentOS 机器的 IP 地址。

在 Windows 的任意文件夹地址栏，或者在运行窗口，输入：\\\ip地址

在win11中默认禁用了“不安全的来宾登录，需要在运行窗口输入 gpedit.msc ，打开本地组策略编辑器

计算机配置 > 管理模板 > 网络 > Lanman 工作站中找到启用不安全的来宾登录

以管理员权限打开powershell，输入如下命令

```shell
Set-SmbClientConfiguration -RequireSecuritySignature $false
```

###### 1.4.3 ftp方法

安装vsftpd服务

```shell
yum install -y vsftpd ftp
```

配置vsftpd

先备份原配置文件

```shell
cp /etc/vsftpd/vsftpd.conf /etc/vsftpd/vsftpd.conf.bak

vim /etc/vsftpd/vsftpd.conf
```

检查  anonymous_enable 、anon_upload_enable、anon_mkdir_write_enable 行配置是否配置正确

可以按 / 进行搜索

```shell
anonymous_enable=YES
```

在最后一行加入如下命令

```shell
anon_root=/data/fileserver
```

启动并设置开机自启

```shell
systemctl start vsftpd
systemctl enable vsftpd
```

验证

文件资源管理器

在顶部文件栏输入 ftp://ip地址

浏览器

在网址栏输入 ftp://ip地址

为什么使用文件资源管理器可以验证，使用浏览器却无法验证

随着互联网安全要求的提高，谷歌、微软、火狐等浏览器厂商达成了共识，决定彻底移除浏览器内置的 FTP 功能

不安全：FTP 是明文传输的，容易被抓包窃听。现代网络都在推行加密的 HTTPS。

用得少：绝大多数普通用户很少直接在浏览器里用 FTP。

代码臃肿： 为了维护这个老旧的协议，浏览器底层需要保留大量容易出漏洞的代码。

###### 1.4.4 http方法

安装http服务

```shell
yum install -y httpd
```

修改配置文件

备份原有配置文件

```shell
cp /etc/httpd/conf/httpd.conf /etc/httpd/conf/httpd.conf.bak
```

```shell
vim /etc/httpd/conf/http.conf
```

删除welcome.conf

```shell
rm /etc/httpd/conf.d/welcome.conf
```

修改根目录

```shell
DocumentRoot "/data/fileserver"
```

修改目录权限

```shell
<Directory "/var/www/html">

<Directory "/data/fileserver">
```

保存并退出

启动服务并设置开机自启

```shell
systemctl start httpd
systemctl enable httpd
```

验证

在浏览器地址栏输入ip地址

###### 3.4.4 http方法

安装http服务

```shell
apt install -y apache2
```

修改配置文件

```shell
cd /etc/apache2/sites-available

vim 000-default.conf
```

```shell
DocumentRoot /data/fileserver
<Directory /data/fileserver>
	Options Indexes FollowSymlinks
	AllowOverride None
	Require all granted
</Directory>
```

 启用配置

```shell
a2ensite 000-default
apache2ctl configtest
```

启动服务

```shell
systemctl start apache2
systemctl enable apache2
```
