## 关键词

`git add`、`git commit`、`git reset`、`git restore`、`git branch`、`git switch`、`git merge`、`git tag`、`git fetch`、`git pull`、`git bundle`、`git clone --mirror`

## 风险提示

执行 `reset --hard`、强制推送或删除分支前，先确认当前分支、未提交修改和远端协作状态。备份仓库时需要同时验证恢复流程，不能只验证备份文件已生成。
